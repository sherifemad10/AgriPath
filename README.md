# Agri Career Navigator

Build a Production-Ready AI Career Mentor Platform for Agricultural Engineers

1. PRODUCT VISION

Build a modern, premium, highly engaging web platform that acts as an AI Mentor, Instructor, Career Guide, and Learning Management System for Agricultural Engineers.

The platform should not feel like a traditional academic learning website.

It should feel like:

"Your AI Mentor for Building a Real Career in Agriculture."

The main objective is to help agricultural engineering students, fresh graduates, junior professionals, and career switchers understand what the real agricultural job market requires, choose a specialization, follow a practical roadmap, learn the required skills, track their progress, build practical experience, and become genuinely job-ready.

The platform should be based on real-world job requirements and practical industry skills, NOT university curricula.

The platform should prioritize:

Real job roles

Real industry skills

Practical knowledge

Tools and technologies used in companies

Field experience

Projects

Problem solving

Portfolio building

Interview preparation

Career readiness

Do NOT design it like Coursera, Udemy, or a university LMS.

It should feel more like a combination of:

## Architecture & Production Deployment

AgriPath is built as an enterprise-grade platform featuring:
- **Client & SSR**: TanStack Start with Vite and React 19.
- **Backend Database**: Native SQLite relational database (`data/agripath.sqlite`) with ACID transactions and strict schemas.
- **Live Scholarly Research Engine**: Multi-source indexing connected in real time to Google Scholar, CrossRef, OpenAlex, and Semantic Scholar.
- **Security**: Cryptographic password hashing (`scrypt`), HttpOnly session security, OWASP headers, and adaptive rate limiting.
